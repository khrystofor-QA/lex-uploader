Lex uploader

A private tool for one YouTube channel.

Lex uploader is a personal script that uploads short educational videos to the owner's own YouTube channel, ЕГЭ наглядно, and reads the view counts of those videos. It is used only by the channel owner and is not offered to anyone else.

It uses the YouTube Data API with the youtube.upload and youtube.readonly permissions, granted by the channel owner.
